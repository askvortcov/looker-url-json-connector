Support

looker-url-json-connector is a free, open-source project maintained by volunteers. Help is given in public on GitHub, on a best-effort basis and with no guaranteed response time.

Before you ask

  • The quickstart covers deployment and the first data source.
  • The config reference explains every setting, and known limits lists what the connector does not do.
  • Error messages name the setting to change. A refused key (HTTP 401 or 403) is fixed by entering a new key, not by changing the URL.

Report a bug or ask a question

Open an issue on GitHub

Include the exact error text, the shape of your API URL and a few rows of made-up data in the real format. Issues are public: remove every key, token and private address before posting.

Report a security problem

Do not open a public issue. Use private vulnerability reporting on GitHub, and include the steps to reproduce without real keys.

Suggest a feature

Check the roadmap first, then open a feature request describing the API you want to read.
