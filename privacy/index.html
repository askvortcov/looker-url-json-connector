Privacy policy

Effective 24 November 2026.

This policy covers the open-source software looker-url-json-connector ("the connector") and this website. Both are provided by the maintainers of the looker-url-json-connector project ("we").

Summary

We do not collect, receive or store your data. The connector is source code that you deploy into your own Google account. We run no server, and the connector contains no analytics, tracking or reporting of any kind.

How the connector handles data

You deploy the connector as a Google Apps Script project that belongs to you. When Looker Studio asks it for data, it runs on Google's infrastructure under your Google account and does the following.

  • API key. The key you enter is stored in the Apps Script user properties of your Google account for that project. It is sent only as a request header, and only to the API host you configured. We cannot read it.
  • Settings. The API URL and the other settings are stored by Looker Studio in your data source. The connector also keeps the last request address it used, in the same private user properties, to check a new key against it.
  • API responses. Responses go from your API to Apps Script and on to Looker Studio. The connector may keep a response in the Apps Script cache of your account for up to five minutes. It stores nothing else.
  • Logs. The connector writes no log entries. Apps Script may record the text of an error in the logs of your own script project. Those texts contain no key and no query string.

None of this is transmitted to us or to any party other than Google, which runs Apps Script and Looker Studio, and the API you chose to connect. Google's handling of your data is governed by the Google Privacy Policy and your agreement with Google. The API you connect is governed by its own provider's terms.

Removing your data

Choosing "Revoke access" for the connector in Looker Studio deletes the stored key and the remembered request address. Deleting the Apps Script project deletes everything the connector stored. Cached responses expire by themselves within five minutes.

This website

This website is static. It sets no cookies, has no forms and no analytics, and loads nothing from third parties. It is hosted on GitHub Pages; GitHub, as the host, may log technical data about visits such as IP addresses, as described in the GitHub General Privacy Statement. We do not receive those logs.

Support requests

Support happens in public issues on GitHub. Anything you post there is public and is handled by GitHub under its own terms. Do not include keys, tokens or personal data in an issue.

Changes

If the way the connector is distributed or the data it handles changes, this page will be updated before the change takes effect, and the date above will change. The history of this page is public in the source repository.

Contact

Questions about this policy can be raised through the support page.
