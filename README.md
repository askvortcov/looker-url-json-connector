# Website of looker-url-json-connector

This branch holds only the static website served by GitHub Pages at
<https://looker-url-json-connector.softec.be>: the connector page, support, the privacy policy
and the terms of service. The connector itself is in the `main` branch.

Plain HTML and one stylesheet, no build step. Every link and asset path starts with `/`.
Edit the files, commit to this branch and push: GitHub Pages publishes it.
